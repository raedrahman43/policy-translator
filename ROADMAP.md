# Roadmap

This roadmap lists opportunities, not delivery commitments.

## Immediate quality work

- Broaden live-tenant verification across multiple external tenants.
- Add rollback guidance for every automated write.
- Improve claims-mapping evidence and extension-attribute handling.
- Add image-dimension validation and richer Company Branding localization support.
- Add automated browser smoke tests for the port-4001 workflow.

## Good community feature candidates

- Microsoft Account provider, after validating the supported Graph model.
- Additional built-in sign-up attributes and page-layout controls.
- Localization and KMSI configuration where documented APIs exist.
- Web application registration alongside the native app path.
- Richer report-only Conditional Access conditions with explicit protected resources.
- Additional gap-report playbooks for common B2C custom-policy patterns.

## Larger investigations

- SAML and workforce federation support.
- Custom authentication extension scaffolding.
- Import/export and rollback planning.
- Hosted documentation and a public feature/community dashboard.

## Guardrails

- No runtime AI dependency in the deterministic translator.
- No automated use of B2C-only provider APIs for External ID.
- No feature is marked complete without honest verification evidence.
- User/password migration remains out of scope.
