# Support

Policy Translator is a community preview and is not covered by Microsoft product
support or an SLA.

## Get help

- Search existing GitHub Issues.
- Open a sanitized bug report for reproducible defects.
- Open a feature proposal for additional Analyzer keys.
- Use GitHub Discussions for usage and design questions once Discussions are enabled.

Do not post customer policy exports, tenant IDs, credentials, tokens, generated state,
or screenshots containing identifiers.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.

Maintainers may close issues that require access to private tenant/customer data or that
cannot be reproduced with a synthetic input.
