      How to run these scripts

      Before you run — one-time setup

      • Install PowerShell 7+ (the pwsh command). These scripts target pwsh, not Windows PowerShell 5.
      • Install the Microsoft Graph module: Install-Module Microsoft.Graph -Scope CurrentUser
      • Sign in as an admin of your External ID tenant who can consent to the Graph permissions listed when you clicked Generate.

      Run order

      Open a terminal inside the extracted package folder (in File Explorer: hold Shift, right-click an empty area, choose Open in Terminal). Confirm you are in the right place with ls — you should see the .ps1 files. Then run each script in order; each prints a result you can verify before moving on.

        The scripts pass context to each other automatically through local .last-*.json files, so keep them together in the same folder. Run them in your own pwsh window (not from an IDE or a subprocess) so interactive sign-in works.

        Before we generate your scripts

        The package you download contains PowerShell scripts that you run against your own Entra External ID tenant. Nothing runs on this server, and no changes are made to your tenant until you run the scripts yourself.
